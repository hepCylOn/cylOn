Scripts `extractHitsFromH5.py` and `extractParticlesFromH5.py` can be used to dump hits and particles information into .txt files.
The information saved for hits is:
- local x (dummy)
- local y (dummy)
- local x error (dummy)
- local y error (dummy)
- global x
- global y
- global z
- global r
- phi converted to short
- charge (dummy)
- cluster size x (dummy)
- cluster size y (dummy)
- layer ID
- particle ID

The information saved for particles is:
- vx
- vy
- vx
- px
- py
- pz
- E
- pT
- eta
- phi
- mass
- charge
- PDG ID
- particle ID
